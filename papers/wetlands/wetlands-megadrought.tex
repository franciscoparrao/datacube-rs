%SCAFFOLD 1.1 The scientific problem.
%  - Central Chile has endured an uninterrupted megadrought since 2010
%    (cite Garreaud et al. 2017, 2020). Wetlands are the ecosystems most
%    exposed to water deficit and the least monitored at scale.
%  - The scientific question, stated plainly and answerably: across the wetland
%    inventory of central Chile, WHERE and SINCE WHEN has surface water/greenness
%    significantly declined, and does exposure differ by wetland type
%    (e.g. urban vs non-urban) and setting? This is the question the paper
%    answers; it could not be answered before at this scale with statistical
%    control.

%SCAFFOLD 1.2 Why it is a computational problem (motivate the CS contribution).
%  - Answering it requires: (a) a MULTI-DECADAL record -> Landsat back to the
%    1980s/2000s fused with Sentinel-2 (2015-), because S2 alone spans only the
%    drought's recovery tail and cannot see its onset (state this as the
%    motivating limitation the pilot revealed);
%  - (b) reduction to the UNIT OF ANALYSIS = the wetland POLYGON, not a bbox;
%  - (c) trend/break statistics VALID under strong seasonality and serial
%    correlation, and CONTROLLED for multiple testing across thousands of
%    wetlands;
%  - (d) all of it at a data volume (decades x two sensors x thousands of
%    polygons) that exceeds memory -> demands bounded-memory, cloud-native
%    streaming.

%SCAFFOLD 1.3 Related work and the gap (closes R-lit — engage, do not name-drop).
%  Cube/ARD engines: gdalcubes, Open Data Cube, openEO, FORCE, xarray, Google
%    Earth Engine -- expose generic reducers, leave domain estimators to the
%    user, and (except GEE) are not built for offline significance-controlled
%    per-polygon trajectories.
%  Time-series methods: Mann-Kendall family and Theil-Sen (with the seasonal
%    Hirsch-Slack and autocorrelation-corrected Hamed-Rao variants), harmonic
%    models / CCDC / CCD-COLD, and the BFAST family incl. BFAST Monitor and
%    BFAST Lite for streaming; trajectory-based LandTrendr for disturbance and
%    recovery; the sits R package for SITS-as-first-class-operators.
%  Field significance: Wilks (2006, 2016) FDR control of spatial test maps.
%  Wetland/water baselines: JRC Global Surface Water (Pekel et al. 2016).
%  THE GAP: none combines (i) per-polygon cross-sensor harmonization, (ii)
%    autocorrelation-aware + FDR-controlled trajectory tests, and (iii)
%    bounded-memory cloud-native execution, as native operators, to answer a
%    wetland-scale question over a multi-decadal record offline.

%SCAFFOLD 1.4 Contributions (explicit list). Computer-science first:
%  C1. A per-polygon CROSS-SENSOR HARMONIZATION (Landsat OLI <-> Sentinel-2 MSI,
%      bandpass adjustment after Roy et al. 2016) computed inside a streaming
%      zonal reduction, yielding consistent multi-decadal per-wetland index
%      trajectories. [Sec.3.1]
%  C2. AUTOCORRELATION-AWARE, MULTIPLE-TESTING-CONTROLLED trajectory analysis as
%      native operators: seasonal and Hamed-Rao Mann-Kendall, Theil-Sen,
%      OLS-CUSUM breaks, with Benjamini-Hochberg/Yekutieli field significance
%      (Wilks), all validated to 1e-9 numerical parity. [Sec.3.3-3.4, 4.1]
%  C3. A BOUNDED-MEMORY, CLOUD-NATIVE chunked execution that makes the
